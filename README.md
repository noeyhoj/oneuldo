## 오늘도가 바라보는 하루

계획대로 보내지 못한 날에는 이미 해낸 일까지 작아 보이곤 합니다. 오늘도는 더 많은 완료를 요구하는 앱이 아니라, **내가 움직인 만큼을 놓치지 않고 기억하게 돕는 앱**입니다.

- 목표는 오늘 꼭 해내고 싶은 일만, 최대 다섯 가지로 가볍게 적습니다.
- 회고는 평가가 아니라 해낸 일을 다시 발견하는 과정으로 만듭니다.
- 목표 밖에서 기억난 작은 행동도 오늘의 성취로 남깁니다.
- 끝내지 못한 일은 실패로 남기지 않고, 내일 다시 고를 수 있게 건넵니다.
- 캐릭터는 방해하지 않으면서 필요한 순간에만 다정한 말을 건넵니다.

## 주요 기능

### 오늘의 TODO

- 하루에 최대 다섯 가지 TODO 작성 및 완료 체크
- 손잡이를 드래그해 중요한 순서대로 바로 재정렬
- 키보드 사용자는 손잡이에서 위·아래 방향키로 순서 변경
- 바꾼 순서는 즉시 저장되어 앱을 다시 열거나 메뉴 막대를 확인해도 그대로 유지
- 메뉴 막대에서 오늘의 TODO 확인 및 완료 처리
- 시작 시간이 지났는데 TODO가 비어 있으면 메뉴 막대 상태 점으로 안내

### 카드로 돌아보는 하루

- `오늘 해낸 일`과 `오늘 하기 어려웠던 일`을 카드 한 장씩 확인
- 어려웠던 일은 그만할지, 내일 다시 고를 수 있게 보낼지 선택
- 회고 마지막에는 목표에 없었지만 기억하고 싶은 일을 딱 한 가지만 기록
- 완료·미완료 일정에 맞춰 짧고 따뜻한 회고 문장을 생성
- 회고 후 TODO가 달라져도 자정까지 오늘 기록을 자동 동기화

### 놓친 날도 사라지지 않게

- 회고하지 않은 채 날짜가 바뀌면 전날 TODO와 체크 상태를 별도로 보관
- 다음 실행에서 `지금 돌아보기` 또는 `기록만 남기기` 중 선택
- 회고를 건너뛰어도 전날의 완료·미완료 상태를 해당 날짜 기록에 그대로 저장
- 내일로 보낸 TODO는 자동으로 채우지 않고, 다음 날 다시 넣을 항목만 직접 선택

### 데스크톱 목표 메이트

- 고양이, 강아지, 토끼, 곰 중 함께할 캐릭터 선택
- 캐릭터 표시·숨기기와 작게·보통·크게 크기 설정
- 이 Mac에서 보이는 화면 비율을 기준으로 디스플레이 크기를 자동 보정해, 다른 Mac과 외부 화면에서도 같은 비율 유지
- 데스크톱 위에서 드래그해 원하는 위치로 이동
- 여러 데스크톱을 사용해도 캐릭터에서 앱을 열면 현재 보고 있는 데스크톱에 표시
- 아직 완료하지 않은 실제 목표를 가끔 언급하는 상황별 응원
- 이미 완료한 목표명은 이후 응원에서 다시 꺼내지 않음

### 기록과 설정

- 캘린더에서 날짜별 성취와 회고 확인
- 기록이 없는 날짜도 눌러 그날을 위한 따뜻한 한마디 확인
- 이전·다음 달 버튼으로 과거와 미래의 월을 자유롭게 이동
- `내 기록`을 열면 기본으로 어제를 선택하고, 오늘 회고를 마쳤다면 오늘을 선택
- 목표 미작성과 회고 대기를 메뉴 막대 아이콘의 서로 다른 점으로 구분
- 시작 시간, 회고 시간, 응원 빈도, 캐릭터와 테마 설정
- 첫 실행에서는 샘플 데이터 없이 온보딩부터 시작
- 설정에서 TODO와 회고가 보관되는 이 Mac의 로컬 저장 경로 확인
- 설정의 `이메일로 버그 제보하기`로 미리 작성된 제보 양식 열기

## 다운로드

현재 배포판은 **Apple Silicon 기반 Mac**을 지원합니다.

1. [GitHub Releases](https://github.com/noeyhoj/oneuldo/releases/latest)에서 최신 `Oneuldo-*-arm64.dmg`를 내려받습니다.
2. DMG를 열고 `오늘도`를 `Applications` 폴더로 옮깁니다.
3. 처음 실행할 때 macOS가 개발자 확인 안내를 표시하면 Finder에서 앱을 우클릭한 뒤 `열기`를 선택합니다.

앱 번들은 패키징 마지막 단계에서 다시 봉인하며, 배포 전에 DMG 무결성과 앱 코드 서명을 검증합니다.

> 현재 개인 배포판은 Apple Developer 공증을 포함하지 않습니다. 목표·설정·회고 데이터는 외부 서버가 아닌 이 Mac의 로컬 저장소에 보관됩니다.

## 직접 실행하기

### 요구 사항

- macOS
- Node.js 22.13 이상
- npm

```bash
git clone https://github.com/noeyhoj/oneuldo.git
cd oneuldo
npm install
npm run desktop
```

배포 파일을 만들고 검증하려면 다음 명령을 사용합니다.

```bash
npm run lint
npm test
npm run desktop:dist
```

## 기술 구성

- Electron
- React 19 / TypeScript
- Vite / vinext
- macOS 네이티브 메뉴 막대 보조 앱(Swift)
- Pretendard Variable

## 데이터와 개인정보

오늘도는 계정 가입을 요구하지 않습니다. 목표, 설정, 회고 기록과 캐릭터 위치는 사용자의 Mac에 저장됩니다. 앱을 삭제한 뒤 데이터까지 완전히 지우려면 macOS의 `Application Support/oneuldo` 폴더도 함께 삭제해야 합니다.
